# flodl 0.8.x guide, frozen

Committed on purpose. This tree is what /guide/0.8.x/ serves, and it keeps
serving it after `docs/` has moved on, so links written against 0.8.x do
not rot.

DO NOT REGENERATE THIS DIRECTORY. It was generated once at release, and it is
expected to diverge from `docs/` at the 0.8.x tag: a typo found in shipped
documentation is fixed by editing the file here, which is the point of
committing it. Regenerating from the tag would silently revert those fixes,
and regenerating from main would publish unreleased content under a released
version number.

To correct something here, edit it here. To change what future releases say,
edit `docs/` and it lands at the next snapshot.
